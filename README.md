# Fidgy — kênh phát hành

Repo này chỉ chứa bản kê phiên bản và các file cài đặt của **Fidgy**.
Mã nguồn nằm ở repo riêng.

- `version.json` — app đọc file này để biết có bản mới hay không.
- Mục **Releases** — file APK của từng bản.

## Cài đặt

Tải APK mới nhất ở mục Releases rồi mở để cài. Android sẽ hỏi cho phép cài
ứng dụng từ nguồn này, chọn Cho phép.

Từ lần sau app tự báo khi có bản mới, tải ở nền rồi cài đè — nhật ký và tiến
độ chơi được giữ nguyên.
